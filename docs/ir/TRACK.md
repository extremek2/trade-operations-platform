## I0 판정

| 항목 | 판정 |
|---|---|
| 첫 수신자 | AI창업가양성과정 수업 운영진과 발표 평가자 |
| 덱의 목적 | 아이디어의 문제 적합성, 제품 범위와 90일 검증 가능성을 검토받는다. |
| 형식 가정 | 10분 이내 라이브 발표와 사전 열람을 모두 견디는 12장 |
| 자금 트랙 | 미확정. 사업자 상태·업력·매출·투자·소재지·런웨이 확인 전 판정하지 않음 |
| 현재 Ask | 투자금이 아니라 제품 방향 피드백과 외부 파일럿 연결 |
| 다음 판정 시점 | 사용자 자격정보 확인 또는 외부 파일럿·유료 증거 확보 시 |

이번 덱은 정부 평가위원, AC, 팁스 운영사와 VC에 발송하지 않는다. 실제 발송본을 만들 때는 상대를 하나만 고르고 공통 9장과 교체 3장을 다시 편집한다.
