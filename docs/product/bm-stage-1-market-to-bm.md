## 1. 이번 단계의 결론

현재는 가격을 확정할 단계가 아니다. 제품 사용자와 문제는 좁혀졌지만 BM 스킬이 요구하는 핵심 입력 중 `지불 주체`, `예산 항목`, `현재 지출액`, `발생 빈도`, `결재 라인`의 외부 고객 증거가 없다.

따라서 이번 단계의 산출물은 가격표가 아니라 다음 세 가지다.

1. 현재 사실과 가설을 분리한 BM 브리지
2. V0·V1·V3 수익모델의 분리
3. 10건의 문제·비용 인터뷰와 3개 가격 실험 설계

## 3. 수익모델을 단계별로 분리한다

### V0 — 내부 ROI 모델

V0는 창업자 본인이 사용하므로 외부 매출이 없다. 수익 대신 다음 내부 가치를 측정한다.

```text
월 내부가치 = 절감한 수기시간 × 본인 시간단가
            + 방지한 원가누락·오발주 손실
            + 재사용한 견적·공급처·문서 정리시간
```

V0에서 측정할 것은 “내가 얼마를 낼 것인가”가 아니라 “이 흐름이 반복되고 어느 단계에서 시간이 사라지는가”다.

### V1 — 소형 수입업자 SaaS

사용자와 지불자가 동일한 1인 사업자를 우선한다. 가장 단순한 후보는 `월 기본료 + 포함 수입 건 + 초과 건당 과금`이다.

```text
월 기본료
  ├─ 후보·견적·원가 시나리오
  ├─ 포함 수입 건 N개
  ├─ 포함 문서/AI 처리량
  └─ 초과 수입 건 또는 자동화 처리량 과금
```

이는 확정 BM이 아니다. 수입이 매월 반복되지 않으면 월 구독보다 건당 또는 분기형이 적합할 수 있다.

### V2 — 팀·외부 협업

수입 건수가 늘어난 회사에는 Workspace 기본료와 사용자·외부 협업 기능을 상향 판매한다. 포워더와 관세사는 초대 사용자이지 초기 지불자로 가정하지 않는다.

### V3 — 공동사입 네트워크

공동사입은 SaaS와 다른 BM이다. 거래를 실제로 중개·수행할 때만 상품 마진 또는 거래액 수수료를 검토한다.

- 구매의향 집계만 제공: SaaS 기능 또는 무료 수요 검증
- 플랫폼이 주문을 중개: 성사 거래 수수료 후보
- 플랫폼이 수입·재판매: 상품 매출과 매출총이익 구조
- 물류·검수·분배: 실비 또는 취급 수수료

IR의 V1 BM 장표에 V3 거래액을 합쳐 큰 매출처럼 표시하지 않는다. GMV와 회사 매출도 분리한다.

|---|---|---|---|---|
| 첫 세그먼트 | 일본 비전기 소비재를 5~30개 시험 수입하는 한국 1인 셀러 | 초기 고객 하나로 고정 | 외부 10명 중 6명 이상이 월 1회 이상 후보를 검토하는지 | V-01 |

| 핵심 문제 | 예상원가와 실제원가·판매결과 단절 | 원가마감·재발주 가치를 과금 | “추천”보다 마감에 더 높은 WTP가 있는지 | V-03 |

| 결재 라인 | 1인 대표 직접결제 가설 | 셀프서브 카드결제 | 전결 한도와 세금계산서 요구 확인 | V-07 |
| 자동화 원가 | LLM·문서 처리량 미측정 | 포함량+초과 과금 | 과업당 COGS 측정 전 무제한 플랜 금지 | V-08 |

| 확장 | 팀 협업, 국가팩, 공동사입 | 상향 판매·거래 수익 | 각 단계의 시작 Gate를 별도 유지 | V-10 |

## 5. 가격은 세 개의 실험으로만 시작한다

아래 금액은 판매가격이 아니라 인터뷰와 랜딩페이지에서 반응을 비교하기 위한 가설이다.

| 실험 | 구조 | 무엇을 검증하는가 | 폐기 조건 |
|---|---|---|---|
| A 건당 | 수입 건 1건 마감 패스 또는 크레딧 | 사용 빈도가 낮아도 결제하는가 | 건마다 결제하는 것이 번거롭다는 응답 우세 |
| B 혼합형 | 월 기본료 + 포함 건수 + 초과 과금 | 예산 예측과 원가 방어가 동시에 가능한가 | 월 사용 공백으로 해지가 반복됨 |
| C 분기형 | 3개월 프로젝트 패스 | 샘플→입고→판매가 월을 넘기는 주기와 맞는가 | 짧은 평가기간 또는 높은 선결제 저항 |

연 구독은 V1 첫 실험에서 제외한다. 가치가 증명되지 않은 상태에서 장기 선결제를 요구하면 가격보다 신뢰 장벽을 측정하게 된다.

### 경쟁 가격이 알려주는 것과 알려주지 않는 것

Faire는 소매상 계정 열람을 무료로 제공하면서 Insider 혜택을 월 19.99달러에 판매하고, 브랜드에는 신규 소매상 주문에 15% 수수료와 첫 주문 수수료를 부과한다.[B-01] 이는 `무료 탐색 + 유료 편의/절감 + 거래 수수료` 조합이 가능함을 보여준다. 하지만 Faire는 규모·배송보조·브랜드 네트워크를 가진 글로벌 마켓플레이스이므로 Import OS의 적정 가격 근거로 직접 사용할 수 없다.

가격은 다음 세 앵커가 모두 확보된 뒤 범위를 정한다.

1. **대체재 비용:** 수기시간 × 실제 시간단가 + 유료 도구·대행비
2. **방치 손실:** 최근 12개월 원가누락·재고·오발주·서류 재작업 비용
3. **경쟁 가격:** 기능과 지불자가 유사한 국내 SaaS·업무대행 가격

## 6. 인터뷰 설계 — 10명, 30분, 최근 사례 중심

### 모집 기준

- 일본 또는 해외상품을 최근 12개월 내 실제로 소싱·수입했거나 구체적으로 준비 중
- 1~3인 사업자
- 스마트스토어·쿠팡·자사몰 중 하나 이상 운영
- 카테고리 2개 이내로 우선 모집
- 경험자 7명, 첫 수입 준비자 3명

### 질문 순서

1. 가장 최근 검토한 해외상품 하나를 화면이나 자료로 보여줄 수 있는가?
2. 후보를 어디서 발견했고 어떤 순서로 탈락·진행을 결정했는가?
3. 견적에서 실제 입고까지 몇 일이 걸렸고 누가 무엇을 기록했는가?
4. 예상원가를 어떤 파일에서 계산했으며 실제원가는 언제 마감했는가?
5. 예상과 실제가 달랐던 최근 사례와 금액은 얼마인가?
6. 판매수수료·반품·광고비를 수입원가와 연결해 보는가?
7. 이 업무는 한 달에 몇 번 발생하고 건당 몇 시간이 드는가?
8. 현재 비용을 내는 도구·대행·인력이 있다면 무엇이며 얼마인가?
9. 이 문제를 해결하지 않고 버티는 이유는 무엇인가?
10. 이 화면을 사용한다면 누가 결제하고 어떤 방식으로 비용처리하는가?
11. 월 구독, 건당, 분기 패스 중 가장 거부감이 적은 것은 무엇이며 왜인가?
12. 사용 후에도 Excel을 유지해야 하는 이유는 무엇인가?

“이 제품을 쓰겠는가?”는 마지막에도 묻지 않는다. 말로 한 의향보다 최근 행동, 자료 제공, 다음 인터뷰 또는 파일럿 참여가 강한 증거다.

## 7. 증거 등급과 통과선

| 증거 | 점수 | 예시 |
|---|---:|---|
| 최근 실제 자료를 익명화해 제공 | 4 | 견적·비용표·수입 건 |
| 본인 상품으로 파일럿 일정 확정 | 4 | 날짜·SKU·담당 확정 |
| 유료 파일럿 또는 보증금 | 5 | 금액보다 실제 결제 중요 |
| LOI 또는 도입검토 확인 | 3 | 비구속임을 명시 |
| 두 번째 사용 | 4 | 반복 문제 증거 |
| 단순 긍정 응답 | 1 | 보조 신호만 |

### Stage 1 완료 Gate

- 적격 인터뷰 10건
- 최근 실제 사례 8건 이상
- 견적·원가·문서 등 익명 자료 5세트 이상
- 월 발생 빈도와 수기시간의 중앙값 계산 가능
- 현재 지출액 또는 방치 손실을 답한 응답자 6명 이상
- 지불 주체와 결재 방식 확인 8명 이상
- 파일럿 참여 의향이 아니라 일정이 정해진 3명 이상

Gate를 통과하지 못하면 가격을 조정하지 않고 세그먼트 또는 문제 정의를 다시 좁힌다.

## 8. V0 내부 원가와 AI COGS 측정

각 자동화 작업은 아래 필드를 남긴다.

| 항목 | 측정 단위 |
|---|---|
| LLM 입력·출력 | 모델, 토큰, 원화 환산비용 |
| 문서 처리 | 파일수, 페이지수, 처리시간, 실패·재시도 |
| 외부 API | 호출수, 성공률, 과금액 |
| 객체 저장 | 용량, 다운로드, 보존일 |
| 사람 검수 | 수정 필드수, 검수시간 |
| 고객지원 | 수입 건당 대응시간 |

```text
수입 건당 변동원가 = 모델·API + 문서처리 + 저장·전송 + 결제 + 사람 검수·지원
추론 원가율 = 월 모델·API 비용 ÷ 월 매출
매출총이익률 = 월 매출 - 고객유발 변동비 / 월 매출
```

매출이 없을 때는 원가율을 만들지 않고 `건당 변동원가`만 측정한다. V1 가격 실험 후에야 매출총이익률을 계산한다.

## 9. BM 경쟁력 가설

| 구조 | 현재 상태 | 필요한 증거 | IR 사용 가능 시점 |
|---|---|---|---|
| 과금 단위 재정의 | 혼합형 후보 | A/B/C 가격 실험 전환율 | 실제 결제 후 |
| 비용 곡선 | 미측정 | 라우팅·캐시 전후 건당원가 | 처리 100건 이상 |
| 데이터 되먹임 | 설계됨 | 실제원가 오차·검토시간 개선 | 수입 건 10건 이상 |
| 공급 측 잠금 | 없음 | 공급사 계약·독점 SKU | 계약 후 |
| 채널 레버리지 | 미확인 | 관세사·포워더 소개 전환 | 파트너 파일럿 후 |
| 다중 사이드 | 장기 가설 | 셀러·공급처 양쪽 성장 | 공동사입 운영 후 |

현재 IR의 해자는 `창업자 도메인 전문성에 기반한 워크플로 설계 가설`이다. 데이터 해자나 네트워크 효과가 이미 있다고 표현하지 않는다.

| 상위 3개 고객이 이탈하면 | 고객 0명 | 초기에는 고객집중도를 트랙션처럼 표시하지 않음 |
| 재계약률 근거는 | 없음 | 두 번째 수입 건·90일 반복으로 대체 |
| CAC 회수가 12개월을 넘는가 | CAC·ARPU 없음 | 창업자 직접 모집 채널부터 실측 |
