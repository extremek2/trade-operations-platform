## 사용 경계

- 지금 덱은 정부지원사업, AC, VC 발송본이 아니다.
- 인터뷰, 유료계약, 파일럿과 LOI는 현재 0건으로 표시한다.
- TAM·SAM·SOM, 가격, 투자금과 밸류는 근거가 생기기 전까지 임의 입력하지 않는다.
- 외부 발송 전에는 수신자를 한 곳으로 확정하고 공통 9장과 교체 3장을 다시 편집한다.

## 다음 보완 순서

1. 실제 3-SKU 원가 마감으로 정량 전후값을 만든다.
2. 동일 세그먼트 8~12명을 인터뷰한다.
3. 외부 파일럿 3곳과 가격 실험을 진행한다.
4. 유료, LOI 또는 반복사용 증거가 생기면 시장·BM·Ask 슬라이드를 갱신한다.
