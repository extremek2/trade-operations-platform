# 공급처 상품 문의 초안

- 날짜: 2026-09-22
- 상태: 공급처 연락처 저장과 상품별 Gmail 작성 창 연결 구현. 실제 발송 없음.

## 흐름

1. 공급처 등록 또는 수정 시 상품 문의용 받는 사람 이메일과 참조 이메일을 저장한다. 참조는 최대 10개이며, 받는 사람 없이 참조만 저장하거나 같은 주소를 중복 저장할 수 없다.
2. 공급 견적 화면에서 문의 주소가 있는 공급처와 공급 조사 중인 상품을 하나 이상 고른다.
3. 상품명과 내부 SKU를 포함한 제목·본문 초안을 만든 뒤 사용자가 수정한다. 공급처 주소는 미리보기에서 확인한다.
4. `Gmail 작성 창 열기`는 받는 사람·참조·제목·본문을 Gmail 작성 URL에 전달한다. 애플리케이션은 발송 API를 호출하거나 이메일을 자동 발송하지 않는다. Gmail 임시보관 여부는 Gmail에서 확인한다.

공급처 주소가 없으면 초안 대상을 선택할 수 없다. 공급처 주소를 수정하면 이전 미리보기를 폐기하고 다시 생성해야 한다. 현재 단계는 이메일 회신이나 첨부파일을 자동 수집하지 않는다.

## 검증

- 백엔드 통합 테스트: 주소 정규화·중복·잘못된 형식·받는 사람 없는 참조·공급처 역할·조직 경계·버전 충돌 및 재조회 통과.
- 프런트엔드 화면 테스트 8개, 프로덕션 빌드 통과.
- Gmail 작성 URL을 브라우저에서 열어 받는 사람·참조·제목·본문이 채워짐을 확인했다. 검증용 초안은 정리했고 기존 샘플 임시보관 메일 1건은 유지했다. 실제 발송 0건.
