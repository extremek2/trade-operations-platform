## 1. 시장 정의

### 고객과 시장을 한 줄로 정의

> 일본 비전기 소비재를 5~30개 단위로 반복 시험 수입해 한국 온라인 마켓에서 판매하는 1~3인 사업자가, 상품 검토·예상원가·수입 문서·실제원가 마감·재발주에 지출하는 소프트웨어 및 수기 운영 예산.

### 우리가 대체하는 예산 항목

현재 확정된 단일 예산 항목은 없다. 다음 네 후보를 1차조사에서 확인한다.

1. 대표 본인의 수기 운영시간
2. Excel·ERP·셀러 도구 등 소프트웨어 비용
3. 수입대행·포워더·관세사에게 지급하는 관리·대행 비용 중 정보정리 부분
4. 원가누락·잘못된 발주·장기재고·재작업으로 발생하는 방치 손실

지불 주체는 1인 사업자 대표로 가정하지만 미확인이다. 사용자가 직원이고 대표가 결제하거나 세무사·대행사가 묶음으로 도입한다면 시장과 BM 구조가 달라진다.

## 4. 현재 시장규모 판정

### TAM

```text
TAM = 국내에서 반복적으로 상업 수입을 수행하는 1~3인 온라인 판매사업자 수
      × Import OS 연간 지불의사액
```

두 항 모두 미확인이다. `전체 온라인쇼핑 거래액`, `해외직구 거래액`, `전체 전자상거래 사업체 수`를 대신 넣지 않는다.

### SAM

```text
SAM = TAM 중 일본 비전기 소비재를 5~30개 단위로 시험 수입하고
      예상·실제 원가를 직접 관리하는 사업자 수
      × 연간 지불의사액
```

일본 상품 취급 여부와 반복 수입 빈도를 동시에 제공하는 공식 교차통계는 이번 조사에서 찾지 못했다. KOSIS/MDIS 또는 별도 표본조사가 필요하다.

### 1년차 SOM

```text
SOM = 실제 접촉 가능한 적격 고객 수
      × 관찰된 유료 전환율
      × 실제 선택된 가격
      × 연간 결제 횟수
```

현재 접촉 채널·전환율·가격·구매횟수가 모두 미확인이다. 1% 점유율 가정은 사용하지 않는다.

## 5. SOM 3방식 계산 시트

### 상향식 — 주력

| 항목 | 값 | Fact ID | 확보 방법 |
|---|---:|---|---|
| 1년 내 직접 접촉 가능한 적격 셀러 | 미확인 | U-01 | 채널별 명단과 월 접촉 역량 |
| 데모→파일럿 전환율 | 미확인 | U-02 | 스모크 테스트 |
| 파일럿→유료 전환율 | 미확인 | U-03 | 실제 결제 |
| 유료 고객 연간 객단가 | 미확인 | U-04 | 가격 실험 |
| 연간 구매·갱신 횟수 | 미확인 | U-05 | 90일 반복 관측 |

```text
상향식 SOM = U-01 × U-02 × U-03 × U-04 × U-05
```

1인 영업의 채널 용량으로 다시 제한한다. 예를 들어 월 실제 미팅 수가 N이면 1년 접촉 상한은 `N×12`이며, 이는 가설이 아니라 실제 접촉 로그로 계산한다.

### 하향식 — 보조

```text
하향식 SOM = 상업 수입 온라인 판매사업자 수
             × 일본·비전기·소량 세그먼트 비중
             × 검증된 유료 채택률
             × 객단가
```

현재 모든 교차 비중이 미확인이다. 공식 통계의 산업분류로 분모를 구한 뒤, 표본조사 비율을 적용하더라도 서로 다른 기준연도를 명시한다.

### 가치식 — 가격 상한 검증

```text
고객당 연간가치 = 절감시간 × 시간단가
                 + 방지한 원가오류·재고손실
                 + 대체한 유료도구·대행비

가치식 SOM = 고객당 연간가치 × 가치 점유율 10~30% × 도달 고객 수
```

가치 점유율은 시장 사실이 아니라 가격 상한을 검토하는 내부 범위다. 실제 고객당 가치가 먼저 측정돼야 한다.

### 수렴 Gate

- 세 방식이 3배 이내면 가장 작은 값을 1년차 SOM으로 채택한다.
- 3~10배 차이면 세그먼트 비중·전환율·가격 가정을 분리해 원인을 찾는다.
- 10배 이상이면 세 방식이 다른 시장을 계산한 것이므로 시장 정의부터 다시 쓴다.

## 6. L2 고객조사 프로토콜

### 표본 구성

문제 검증은 같은 세그먼트 10명으로 고정한다.

- 1~3인 한국 온라인 판매사업자
- 최근 12개월 일본 또는 해외상품을 실제 상업 수입했거나 발주 직전까지 검토
- 비전기 생활·수납·문구·취미 카테고리 중심
- 경험자 7명, 첫 수입 준비자 3명
- 지인·투자자·동종 솔루션 창업자는 핵심 표본에서 제외

가격 검증에는 동일 세그먼트 15~20명이 필요하므로 문제 인터뷰 이후 5~10명을 추가한다.

### 인터뷰 기록 규격

| 필드 | 기록 원칙 |
|---|---|
| 대상·세그먼트 | 업력, 인원, 채널, 카테고리, 수입국 |
| 최근 사례 | 추상적 의견이 아니라 마지막 수입 건의 시간순 사건 |
| 지불 주체 | 실제 카드·계좌·세금계산의 결정자 |
| 예산 항목 | 소프트웨어, 대행, 물류, 대표시간 중 실제 출처 |
| 현재 지출액 | 월/건/연 단위와 포함 범위 |
| 대체 수단 | Excel, 사람, ERP, 구매대행, 아무것도 안 함 |
| 결재 라인·기간 | 반대자, 승인자, 결제까지 걸린 날 |
| 발생 빈도 | 후보검토·샘플·수입·마감 각각 |
| 최근 손실 | 금액, 시간, 재고수량과 증빙 가능 여부 |
| 원문 인용 | 해석과 분리해 25단어 이내 핵심 발언 |
| 증거 | 익명 자료, 다음 미팅, 파일럿 일정, 실제 결제 |

### 정량화할 최소값

- 월 상품검토·수입 건수 중앙값과 사분위
- 수입 건당 수기시간 중앙값
- 현재 지출액 중앙값
- 최근 손실 경험 비율과 손실액 범위
- 지불주체·사용자 일치 비율
- 가격 단위 선호 분포
- 파일럿 일정 확정률
- 제품이 없으면 매우 실망 응답 비율은 데모 사용 후 별도 측정

## 7. WTP·스모크 테스트

### 실험 A — 수동 원가 마감 서비스

고객의 익명화된 견적·비용표를 받아 사람이 Import OS 형식으로 정리하고 예상·실제 차이 리포트를 제공한다. 제품이 없어도 문제와 지불행동을 검증할 수 있다.

- 성공 기준: 10명 중 3명이 자료 제공
- 강한 성공 기준: 1명 이상 소액 유료 또는 환불 가능한 예약금 결제
- 실패 해석: 자료 민감도, 문제 약함, 신뢰 부족을 구분해 후속 질문

### 실험 B — 랜딩페이지 CTA

- CTA 1: 내 수입 건 무료 진단 신청
- CTA 2: 실제원가 마감 파일럿 신청
- CTA 3: 일본 소량사입 대기자 등록

세 CTA를 한 전환율로 합치지 않는다. 방문 출처, 적격 사업자 여부, 클릭, 폼 완료와 상담 일정을 분리한다.

### 실험 C — 가격 민감도

문제 인터뷰 이후에만 네 가격 질문을 한다.

1. 너무 싸서 신뢰하기 어려운 가격
2. 싸다고 느끼는 가격
3. 비싸지만 검토할 가격
4. 절대 구매하지 않을 가격

건당·월 혼합형·분기 패스의 단위도 함께 비교한다. 말로 한 WTP는 확정 매출로 보지 않고 실제 결제 이전까지 C등급이다.

## 10. 현재 판정

### 확인된 것

- 온라인 판매와 일본발 상품 구매라는 배경 활동은 실제로 존재한다.
- 중소기업 수입은 거시적으로 유의미하지만 우리 고객 수와 동일하지 않다.
- 일본 소량 조달과 공동 MOQ의 경쟁·대체재가 이미 존재한다.
- 전자상거래 통관의 사업자 데이터화가 강화되고 있다.
- 공공 통계로 HS·국가별 상품 흐름을 확인할 수 있다.

### 아직 확인되지 않은 것

- 반복적으로 상업 수입하는 1~3인 온라인 셀러 수
- 그중 일본·비전기·소량 세그먼트 비중
- 월 수입 빈도와 원가마감 수행률
- 현재 지출액·방치 손실·지불의사
- 실제 결제자와 구매 주기
- 도달 가능한 판매채널과 전환율

### Stage 1 시장 Gate

현재 L1은 완료됐지만 L2·L3는 미통과다. 그러므로 IR Deck에 TAM·SAM·SOM 금액, CAGR, 1년차 매출을 확정치로 넣지 않는다.

다음 단계 진입 조건:

1. 같은 세그먼트 인터뷰 10건
2. BM 5필드 유효 응답 8건 이상
3. 익명 실무자료 5세트
4. 실제 결제 또는 예약금 1건 이상을 목표로 한 스모크 테스트
5. SOM 3방식의 모든 항에 Fact ID 부여
6. 세 방식 결과가 3배 이내로 수렴
