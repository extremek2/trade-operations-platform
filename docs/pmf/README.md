# PMF 검증·마케팅 작업 현황

- 기록 기준: 2026-09-15. 이 문서는 그날 확인한 상태를 보존하며, 이후 네이버·Gmail 상태를 자동으로 반영하지 않는다.
- 대상 제품: Import OS의 첫 일본 매입 실험. 대상 고객은 일본에서 소량으로 사입해 국내에 유통하는 1인 셀러라는 **가설**이다.

## 확인된 진행 상태

| 작업 | 확인된 결과 | 남은 일 |
|---|---|---|
| 제품 분석 | PMF **0/4단계**. 최근 목표 고객 인터뷰와 지불·재사용 근거가 없어 1단계를 통과시키지 않았다. | 최근 거래를 한 목표 고객과 인터뷰하고 기존 도구, 건당 시간·비용, 매입 보류 사례를 기록한다. |
| 고객 발굴 | 공개 후보 조사와 로컬 인터뷰 요청 초안·미리보기까지 진행. **Gmail 임시보관 0통, 실제 발송 0통, 답장 0건, 인터뷰 0건**. | 후보 적합성과 업무용 연락처를 재검증한 뒤 실제 인터뷰를 요청한다. |
| 네이버 블로그 | 「일본 소량수입 원가 계산, MOQ와 현금흐름까지 보는 방법」 **본문을 임시저장**. 저장 목록에서 정확한 제목을 확인하고 새로고침 후 다시 열어 마지막 문장을 검증했다. **발행 0건**. | 아래 이미지 2개를 본문에 삽입하고 다시 임시저장·재조회한다. |

블로그 이미지는 제작됐지만, Chrome용 ChatGPT 브라우저 확장 프로그램의 `Allow access to file URLs` 설정이 꺼져 파일 선택 단계에서 업로드가 거부됐다. 저장된 네이버 글에는 이미지가 없다. 설정을 켠 뒤 [초안](blog/drafts/post_001.md)의 `[[이미지:1]]`·`[[이미지:2]]` 위치에 [원가 구성](blog/images/원가구성.png)과 [MOQ 현금흐름](blog/images/MOQ현금흐름.png)을 넣어야 한다. 저장소의 이미지 경로는 보관용 상대 경로이며, 네이버에 저장된 본문에는 자리 표시 문구를 입력하지 않았다.

[키워드 후보](blog/keywords.csv)의 블로그 문서 수는 검색 화면에서 총수를 확인할 수 없어 `측정불가`로 유지했다. [경쟁 글 조사](blog/competitors.md)는 2026-09-15 네이버 블로그 검색의 1페이지 표본과 본문을 직접 읽은 글 2개를 구분해 기록했다. [SEO 점검](blog/seo_check.md)은 로컬 초안 기준이고, 네이버 편집기의 이미지 2개까지 검증했다는 의미는 아니다.
